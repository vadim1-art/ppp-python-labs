## Описание проекта

Классическая игра «Сапёр» на Python и `tkinter`. На прямоугольном поле
спрятаны мины. Игрок открывает клетки, а цифры подсказывают, сколько мин
рядом. Нужно открыть все безопасные клетки и не подорваться. Сначала
реализован классический вариант (как в Windows): три уровня сложности,
флажки, счётчик мин, таймер и кнопка-смайлик. Затем добавлены анимации,
особое поле, «аккорд» и таблица рекордов. Вся графика (клетки, мины,
флажки, семисегментные индикаторы, смайлик) нарисована примитивами холста
без внешних картинок.

## Функциональные возможности

### Основной функционал (классические правила)

- 💣 Поле с минами и цифрами — число мин среди восьми соседей клетки
- 🛡️ Первый ход всегда безопасен: мины расставляются после первого клика,
  и вокруг этой клетки их нет
- 🌊 Пустые области открываются автоматически (обход в ширину, BFS)
- 🚩 Флажки на правую кнопку мыши
- 🔢 Счётчик оставшихся мин и таймер на красных семисегментных индикаторах
- 🙂 Кнопка-смайлик: новая игра. Выражение меняется: 😮 — кнопка мыши
  зажата, 😵 — проигрыш, 😎 — победа
- 💥 При проигрыше показываются все мины, а неверные флажки зачёркиваются
- 🏆 При победе все мины автоматически помечаются флажками

### Дополнительный функционал

- 🎚️ Уровни сложности: Новичок 9×9 (10 мин), Любитель 16×16 (40 мин),
  Профессионал 30×16 (99 мин) и **особое поле** со своими размерами
- 🎹 «Аккорд»: клик по открытой цифре (или средней кнопкой мыши) открывает
  всех соседей, если вокруг стоит нужное число флажков
- ❓ Знаки вопроса: флажок → «?» → пусто (включаются в меню)
- ✨ Анимации: открытие области «волной» от точки клика, взрыв мин цепочкой
  от подорвавшейся клетки, «вдавленные» клетки под зажатой кнопкой
- 🥇 Таблица рекордов: лучшее время на каждом уровне хранится в JSON-файле
- 📖 Справка с правилами, горячие клавиши
- ✅ Модульные тесты логики игры (38 тестов)

## Как это работает

- **Расстановка мин.** Мины ставятся только при первом открытии клетки
  (`Board.place_random_mines`). Клетка клика и её соседи исключаются из
  кандидатов, затем `random.sample` выбирает нужное число позиций. Если мин
  слишком много и места не хватает, защищается только сама клетка.
- **Цифры.** Для каждой клетки считается число мин среди восьми соседей
  (`Board.neighbors` перебирает смещения −1..1 по обеим осям).
- **Открытие области.** `Board.open_area` — обход в ширину (очередь `deque`).
  От клетки с нулём волна идёт к соседям и останавливается на клетках
  с цифрами. Флажки не открываются. Клетки возвращаются в порядке обхода.
- **Анимация волны.** Отрисовщик группирует открытые клетки по расстоянию
  Чебышёва до клетки клика (`max(|Δстрока|, |Δстолбец|)`) и рисует «кольца»
  с задержкой через `canvas.after`. Каждой анимации присваивается номер
  «поколения». Если игрок начал новую партию, старые отложенные кадры
  ничего не рисуют.
- **Победа.** Партия выиграна, когда не осталось закрытых клеток без мин.
- **Таймер** запускается первым ходом и останавливается в конце партии.
  Часы передаются в модель параметром, поэтому в тестах время подменяется.

- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** только стандартная библиотека — `tkinter`, `random`, `json`,

## Установка и запуск

### 1. Клонирование репозитория

```bash

cd ppp-python-labs
```

Виртуальное окружение `venv/` уже лежит в корне репозитория (оно общее для
всех лабораторных).

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

Окружение создано на Linux. Если на вашей ОС оно не активируется,
пересоздайте его и активируйте снова:

```bash
python -m venv venv
```

### 3. Установка зависимостей

```bash
pip install -r lab-3.3-minesweeper/requirements.txt
```

Внешних библиотек нет, поэтому команда ничего не установит. Файл есть
по требованиям к оформлению.

### 4. Запуск программы

```bash
cd lab-3.3-minesweeper
python main.py
```

### 5. Управление

| Действие | Как |
|---|---|
| Открыть клетку | левая кнопка мыши |
| Флажок / «?» / снять отметку | правая кнопка мыши |
| «Аккорд» — открыть соседей цифры | левая кнопка по открытой цифре или средняя кнопка |
| Новая игра | смайлик, F2 или меню «Игра → Новая игра» |
| Уровень сложности | клавиши 1, 2, 3 или меню «Игра» |
| Особое поле | меню «Игра → Особое поле…» |
| Знаки вопроса вкл/выкл | меню «Игра → Отметки (?)» |
| Таблица рекордов | меню «Игра → Рекорды…» |
| Правила | F1 или меню «Справка» |

На macOS правая и средняя кнопки мыши переназначаются автоматически.

## Тесты

```bash
cd lab-3.3-minesweeper
python -m unittest -v
```

Что проверяется: соседи и границы поля, расстановка мин и безопасный первый
ход, подсчёт цифр, открытие областей (BFS), флажки и знаки вопроса,
«аккорд» (верный и неверный флажок), победа и поражение, таймер (с
подменёнными часами), рекорды (в том числе повреждённый файл), уровни
сложности и формат счётчика.

## Структура проекта

```
lab-3.3-minesweeper/
├── README.md                    # этот файл
├── requirements.txt             # зависимости (только стандартная библиотека)
├── main.py                      # точка входа
├── screenshots/                 # скриншоты и GIF для README
├── src/
│   ├── __init__.py
│   ├── config.py                # константы: размеры, цвета, скорость анимаций
│   ├── app.py                   # MinesweeperApp: окно, меню, мышь, таймер
│   ├── models/
│   │   ├── __init__.py
│   │   ├── cell.py              # Cell и Mark — клетка и её пометка
│   │   ├── board.py             # Board — поле, мины, цифры, открытие областей
│   │   ├── game.py              # MinesweeperGame, GameState — правила и таймер
│   │   ├── difficulty.py        # Difficulty — уровни сложности
│   │   └── records.py           # RecordsTable — рекорды в JSON
│   ├── renderers/
│   │   ├── __init__.py
│   │   ├── board_renderer.py    # BoardRenderer — клетки и анимации
│   │   └── hud_renderer.py      # HudRenderer — индикаторы и смайлик
│   └── widgets/
│       ├── __init__.py
│       └── dialogs.py           # окна «Особое поле», «Рекорды», правила
└── tests/
    ├── __init__.py
    ├── test_board.py            # тесты поля
    ├── test_game.py             # тесты правил игры
    └── test_records_and_levels.py
```

**Назначение основных классов:**

| Класс | Ответственность |
|---|---|
| `Cell` | одна клетка: мина, число соседних мин, открыта ли, пометка |
| `Board` | сетка клеток, соседи, расстановка мин, открытие областей |
| `MinesweeperGame` | правила: ходы, флажки, «аккорд», победа/поражение, таймер |
| `Difficulty` | размер поля и число мин; пресеты и особый уровень |
| `RecordsTable` | загрузка и сохранение лучших результатов |
| `BoardRenderer` | рисует клетки и анимирует открытие и взрыв |
| `HudRenderer` | рисует семисегментные индикаторы и смайлик |
| `MinesweeperApp` | окно и меню, переводит действия мыши в ходы игры |

**Почему такая структура:** использован объектно-ориентированный подход
с разделением «модель — отображение — управление». Модели (`models/`) ничего
не знают о `tkinter` и полностью покрыты тестами. Отрисовщики (`renderers/`)
только читают состояние игры и рисуют его. `app.py` связывает всё вместе.
Поэтому оформление можно менять, не трогая правила игры, и наоборот.

## Пример использования

1. Запустите `python main.py`: откроется поле «Новичок» 9×9.
2. Кликните левой кнопкой по любой клетке: откроется безопасная область,
   и пойдёт таймер.
3. Найдите клетки, где мина однозначна (например, у «1» остался всего один
   закрытый сосед), и поставьте флажки правой кнопкой.
4. Кликните по цифре, вокруг которой уже стоят все флажки: её остальные
   соседи откроются разом.
5. Откройте все безопасные клетки: смайлик наденет очки, а время попадёт в
   таблицу рекордов, если оно лучшее.
6. Для сложной партии нажмите 3 («Профессионал») или задайте своё поле через
   «Игра → Особое поле…».
