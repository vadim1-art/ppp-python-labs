## Описание проекта

Программа рисует фрактальное дерево. От нижнего края окна поднимается
вертикальный ствол. Из его конца выходят две ветви поменьше, повёрнутые
на заданный угол в обе стороны, из концов этих ветвей — ещё по две, и так
10 итераций (1023 ветви). Угол ветвления, коэффициент убывания длины и
глубина рекурсии меняются слайдерами в реальном времени. Дерево плавно
вырастает при запуске, а в режиме анимации угол меняется сам, и дерево
перетекает из одной формы в другую, как на анимации в задании.

## Функциональные возможности

### Основной функционал

- 🌳 Рекурсивное построение дерева (по умолчанию 10 итераций, угол 30°, k = 0.67)
- 🎚️ Слайдер угла ветвления 0°–180°
- 📏 Слайдер коэффициента убывания длины 0.30–0.85

### Дополнительный функционал

- 🔢 Слайдер глубины рекурсии 1–13 (до 8191 ветви)
- 🌱 Анимация роста: ветви каждого уровня плавно «прорастают» из концов предыдущих
- 🎞️ Анимация угла (клавиша Пробел): угол плавно ходит от 0° до 180° и обратно
- 🎨 Палитры: «Белый» (как в задании), «Дерево», «Сакура», «Осень», «Неон», «Радуга».
  Цвет и толщина ветви зависят от её уровня
- 🖼️ Автомасштаб: дерево всегда целиком вписывается в окно, окно можно растягивать
- ⌨️ Управление с клавиатуры (работает и в русской раскладке)
- 📊 Строка состояния: число ветвей, угол и коэффициент
- ✅ Модульные тесты математической модели (16 тестов)

## Как это работает

### Алгоритм (рекурсия)

Метод `FractalTree._grow(x, y, heading, length, level)`:

1. Если `level == depth`, рекурсия останавливается.
2. Вычисляется конец ветви:
   `x2 = x + length · cos(heading)`, `y2 = y + length · sin(heading)`.
3. Отрезок добавляется в список.
4. Метод дважды вызывает сам себя из точки `(x2, y2)` с направлениями
   `heading + angle` и `heading − angle` и длиной `length · k`.

Ствол растёт вертикально вверх (`heading = 90°`). Всего получается
`1 + 2 + 4 + … + 2^(n−1) = 2^n − 1` ветвей. При угле 0° дерево
вытягивается в линию длиной `L · (1 − kⁿ) / (1 − k)` (сумма геометрической
прогрессии). Отсюда выбрана длина ствола — около трети высоты окна: при
k = 0.67 крона как раз заполняет окно, как ствол «примерно до центра» в задании.

### Модель, отрисовка, анимация

- Модель считает ветви в «мировых» координатах: основание ствола в точке
  (0, 0), ось Y вверх, длина ствола 1. Модель не зависит от `tkinter`,
  поэтому её легко тестировать.
- Отрисовщик переводит координаты в пиксели и подбирает масштаб: если крона
  не помещается в окно, масштаб уменьшается. Если ветви опускаются ниже
  основания (углы больше 90°), основание поднимается.
- Чтобы анимация шла плавно, линии на холсте не пересоздаются каждый кадр:
  если число ветвей не изменилось, у существующих линий меняются только
  координаты (`canvas.coords`).
- Главный цикл — метод `_tick`, который вызывается через `root.after`
  примерно 60 раз в секунду. Он двигает анимации и перерисовывает холст,
  только если что-то изменилось.
- Анимация роста хранит «прогресс» `p` (сколько уровней уже выросло).
  Ветвь уровня `L` рисуется на долю `clamp(p − L, 0, 1)` своей длины.

## Структура проекта

```
lab-3.1-fractal-tree/
├── README.md                  # этот файл
├── requirements.txt           # зависимости (только стандартная библиотека)
├── main.py                    # точка входа
├── screenshots/               # скриншоты и GIF для README
├── src/
│   ├── __init__.py
│   ├── config.py              # константы: размеры, цвета, параметры по умолчанию
│   ├── app.py                 # класс FractalTreeApp: окно, главный цикл, клавиши
│   ├── models/
│   │   ├── __init__.py
│   │   └── tree_model.py      # Segment, FractalTree (рекурсия), grow_stage, bounding_box
│   ├── renderers/
│   │   ├── __init__.py
│   │   └── tree_renderer.py   # TreeRenderer: масштаб, цвета, рисование на Canvas
│   └── widgets/
│       ├── __init__.py
│       └── controls.py        # Slider и ControlPanel: слайдеры, кнопки, палитра
└── tests/
    ├── __init__.py
    └── test_tree_model.py     # тесты математической модели
```

**Назначение основных модулей:**

- `main.py` — точка входа: создаёт `FractalTreeApp` и запускает главный цикл.
- `tree_model.py` — математика дерева: рекурсивное построение ветвей,
  частичное дерево для анимации роста, габариты дерева.
- `tree_renderer.py` — перевод мировых координат в экранные, автомасштаб,
  палитры, эффективное обновление линий.
- `controls.py` — панель управления. О действиях пользователя сообщает через
  функции обратного вызова и модель напрямую не меняет.
- `app.py` — связывает модель, отрисовщик и панель, крутит анимацию.

**Почему такая структура:** код разделён по принципу «модель — отображение —
управление». Модель не зависит от `tkinter` и проверяется тестами без
графического окна. Отрисовщик и элементы управления можно менять, не трогая
математику.

## Пример использования

1. Запустите `python main.py`: дерево вырастает от ствола к листьям примерно
   за 2 секунды.
2. Подвигайте слайдер «Угол ветвления»: при 30° получается обычное дерево,
   при 90° — «H-дерево» из прямых углов, при углах больше 120° ветви
   загибаются вниз и складываются в треугольные «снежинки».
3. Уменьшите коэффициент длины до 0.5: ветви перестают перекрываться, видна
   структура фрактала. Увеличьте до 0.8: крона становится густой.
4. Нажмите Пробел: угол начнёт меняться сам, и дерево будет перетекать
   между формами. Снова Пробел — пауза.
5. Выберите палитру «Сакура» или «Радуга» и поднимите глубину до 12–13.
